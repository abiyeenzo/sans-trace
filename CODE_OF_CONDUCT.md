# Code de conduite

Sois respectueux. Pas d'insultes, de harcèlement, de discrimination ni de publication de données personnelles. Les discussions restent sur le projet.

Le mainteneur peut modifier, masquer ou supprimer tout commentaire, issue ou pull request qui ne respecte pas ces règles, et bloquer son auteur.

Pour signaler un comportement, utilise le signalement GitHub du contenu concerné.
