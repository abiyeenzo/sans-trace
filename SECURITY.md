# Politique de sécurité

## Signaler une faille

Utilise le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability** sur le dépôt `abiyeenzo/sans-trace`. N'ouvre pas d'issue publique et ne publie pas de détails avant la correction. Si tu ne peux pas utiliser GitHub, écris à abiyeenzo@gmail.com avec "Faille Sans Trace" en objet, sans joindre de données privées.

Indique : ce que tu as trouvé, les étapes pour le reproduire, l'impact, et si possible une idée de correctif.

## Ce que tu peux attendre

- Un accusé de réception sous 7 jours.
- Une réponse sur la gravité et le calendrier de correction.
- Un remerciement dans les notes de version si tu le souhaites.

## Périmètre

Dans le périmètre : le site, ses fonctions `api/`, l'analyse des fichiers images, les workflows GitHub.

Hors périmètre : les failles de l'hébergeur ou du navigateur, le spam, les tests de charge, l'ingénierie sociale.

## Bonnes pratiques de test

Teste uniquement avec tes propres données. N'accède pas aux données d'autres personnes et ne perturbe pas le service.
